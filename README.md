# 🌦 Weather App (Android)

A modern Android weather application built using **Kotlin and Jetpack Compose**.

## Features
- Current weather based on location
- Search weather by city
- Next 7 hours forecast
- 7 days weather forecast
- Dynamic weather backgrounds
- Day/Night detection using timezone

## Tech Stack
- Kotlin
- Jetpack Compose
- MVVM Architecture
- Retrofit
- Open-Meteo API
- Location Services
